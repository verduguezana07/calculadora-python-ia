# 🧮 Calculadora Python com IA

## 📌 Sobre o projeto
Projeto de uma calculadora desenvolvida em Python com apoio de Inteligência Artificial, como prática de programação, lógica e execução de código.

## ⚙️ Funcionalidades
- Adição
- Subtração
- Multiplicação
- Divisão
- Cálculo de porcentagem

## 🛠️ Tecnologias utilizadas
- Python 3
- Google AI Studio — apoio na criação e revisão do código
- Visual Studio Code — ambiente de desenvolvimento
- GitHub — versionamento e publicação

## ▶️ Como executar
1. Instale o Python 3 no computador.
2. Baixe o arquivo `calculadora.py`.
3. Abra o terminal na pasta onde o arquivo está salvo.
4. Execute:

```bash
py calculadora.py
```

Em outros sistemas, o comando pode ser `python3 calculadora.py`.
