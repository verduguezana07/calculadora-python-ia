## 🌷 Sobre o projeto

A **Calculadora Ana** é um projeto desenvolvido durante um desafio de Engenharia de Software com apoio de ferramentas de Inteligência Artificial.

O objetivo foi aprender a criar, compreender, modificar e testar uma aplicação, aplicando conceitos básicos de programação.

O projeto começou com uma calculadora em Python e evoluiu para uma interface visual utilizando HTML, CSS e JavaScript.

## 🎯 Etapas do desafio

### 💗 Tarefa 1 — Criando a calculadora

- Desenvolvimento de uma calculadora em Python.
- Implementação das quatro operações matemáticas básicas.
- Estudo de funções, variáveis e estruturas condicionais.
- Compreensão da lógica de programação com apoio de IA.

### 💜 Tarefa 2 — Engenharia de Software com IA

- Importação e análise do projeto no Google Antigravity.
- Exploração da organização do código.
- Verificação da funcionalidade de porcentagem.
- Análise das operações existentes.
- Teste manual da aplicação Python.

### 🌸 Evolução extra — Interface web

Como melhoria adicional, desenvolvi uma versão visual da calculadora com:

- Interface em tons de rosa e lilás.
- Botões interativos.
- Histórico da operação no visor.
- Operações matemáticas e porcentagem.
- Tratamento de divisão por zero.

## 🧮 Funcionalidades

| Operação | Exemplo |
|---|---|
| ➕ Adição | 10 + 5 = 15 |
| ➖ Subtração | 20 - 8 = 12 |
| ✖️ Multiplicação | 6 × 4 = 24 |
| ➗ Divisão | 20 ÷ 4 = 5 |
| 💯 Porcentagem | 15% de 200 = 30 |
| 🔢 Potenciação | 2³ = 8 |

## 🚀 Como executar

### Versão Python

1. Tenha o Python instalado.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
py calculadora.py
```

### Versão web

1. Abra a pasta `web`.
2. Execute o arquivo `index.html` no navegador.
3. Utilize os botões para realizar os cálculos.
